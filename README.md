# NMessenger

Полноценный веб‑мессенджер в стиле MAX / Telegram: один файл фронтенда (`index.html`) + Node.js‑сервер (`server.js`).

## Запуск

```bash
npm install
npm start            # http://localhost:10000
```

Опционально скопируйте `.env.example` в `.env` и заполните ключи LiveKit — тогда заработают групповые звонки.

> Для звонков (микрофон/камера/экран) браузеру нужен **HTTPS или localhost**. При выкладке на сервер
> поставьте перед Node любой reverse‑proxy с TLS (Caddy, nginx + certbot, Cloudflare Tunnel).

## Что умеет

**Чаты**: личные, группы, каналы (только админы пишут, подписка по `@handle` или ссылке `/?start=handle`),
Избранное, секретные чаты со сквозным шифрованием (ECDH P‑256 + AES‑256‑GCM прямо в браузере).
В группах и каналах владелец/админы могут **добавлять и исключать участников, назначать и снимать администраторов**,
переименовывать чат (информация о чате → меню участника). Все изменения отмечаются системными сообщениями.

**QR‑коды**: у любого чата с `@handle` (и у личных) есть **QR‑код и ссылка** — тот, кто отсканирует, сразу попадает в чат
(вступает в группу / подписывается на канал). Свой QR — в профиле. Сканер: «Меню → Сканировать QR‑код»
(камера через BarcodeDetector, либо вставить ссылку вручную).

**Вход по QR‑коду**: на экране входа вкладка «QR‑код» показывает код; отсканируйте его с устройства, где вы уже вошли
(Меню → Сканировать QR‑код) — новая сессия появится без ввода пароля. Код живёт 3 минуты и обновляется сам.

**Сообщения**: ответы, редактирование, удаление, пересылка, реакции, избранное (звёздочка), поиск по чату
и глобальный, форматирование (`**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `код` ``, `||спойлер||`,
`@упоминания`, ссылки), фото с превью и лайтбоксом, любые файлы до 10 МБ (drag‑and‑drop / вставка из буфера),
голосовые сообщения с аудиоплеером, индикатор «печатает», галочки доставки/прочтения, черновики.

**Звонки**: по умолчанию через **LiveKit (SFU)** — если в `.env` заданы `LIVEKIT_URL / LIVEKIT_API_KEY / LIVEKIT_API_SECRET`
(переключатель «Через LiveKit» — в Настройки → Звонки). Без ключей звонки идут напрямую по WebRTC (P2P, DTLS‑SRTP).
Аудио/видео, **демонстрация экрана**, выбор микрофона / камеры / динамиков и качества показа экрана (720p…4K, 15/30/60 fps)
прямо во время звонка (кнопка «Устройства») или заранее в Настройки → Звонки. Свёрнутый и полноэкранный режим,
индикатор качества, лог звонков в чате.

**Организация**: папки чатов (по типам и конкретным чатам), закрепление, «без звука», скрытие чата,
очистка истории, непрочитанные, счётчик во вкладке браузера, системные уведомления и звуки.

**Профиль и настройки**: аватар, имя, «о себе», три темы (тёмная / полночь / светлая), размер шрифта,
Enter/Ctrl+Enter, приватность (последний визит, отчёты о прочтении, кто может звонить/писать),
блокировка и жалобы, смена пароля, активные сессии с возможностью завершить.

**Боты — через @BotFather**, как в Telegram: откройте чат с BotFather (Меню → Боты) и отправьте `/newbot`,
затем имя и `username` (должен оканчиваться на `bot`). BotFather выдаст API‑ключ и готовый `curl`.
Команды: `/newbot`, `/mybots`, `/token`, `/revoke`, `/setname`, `/setabout`, `/setuserpic`, `/deletebot`, `/cancel`.
HTTP API бота: `POST /api/bot/<token>/sendMessage {"chat_id":"...","text":"..."}`, `GET /api/bot/<token>/me`.
Добавить бота в группу/канал — через информацию о чате.

**Лимиты**: файлы до **10 МБ** (проверяется и в браузере, и на сервере), текст до 4000 символов,
имена/описания/пароли/поиск — ограничены по длине во всех полях.

Горячие клавиши: `Ctrl+K` — поиск, `Ctrl+F` — поиск по чату, `↑` — редактировать последнее, `Esc` — закрыть.

## Структура

- `server.js` — Express + Socket.IO, данные в `data/store.json`, файлы в `data/files/`
- `index.html` — весь фронтенд (HTML + CSS + JS без сборки и фреймворков)

## Серверный API (для интеграций)

Socket.IO (после `auth`): `open_dm`, `open_handle`, `join_handle`, `create_group`, `create_channel`,
`add_members {conversationId, members[]}`, `remove_member {conversationId, user}`, `set_admin {conversationId, user, admin}`,
`update_conversation {conversationId, name}`, `send_message`, `edit_message`, `delete_message`, `react`, `call_invite` и др.

HTTP: `POST /api/register`, `POST /api/login`, `GET /api/sessions`, `POST /api/upload` (≤ 10 МБ),
`POST /api/qr/new` → `{id, secret, ttl}`, `GET /api/qr/status/:id?secret=…`, `POST /api/qr/approve {id}` (Bearer),
`POST /get-livekit-token`, `GET /livekit-status`, `GET /api/bot/:token/me`, `POST /api/bot/:token/sendMessage`.
