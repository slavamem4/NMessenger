# NMessenger

Полноценный веб‑мессенджер в стиле MAX / Telegram: один файл фронтенда (`index.html`) + Node.js‑сервер (`server.js`).

## Запуск

```bash
npm install
npm start            # http://localhost:10000
```

Опционально скопируйте `.env.example` в `.env` и заполните ключи LiveKit — тогда заработают групповые звонки.

> Для звонков (микрофон/камера/экран) браузеру нужен **HTTPS или localhost**. При выкладке на сервер
> поставьте перед Node любой reverse‑proxy с TLS (Caddy, nginx + certbot, Cloudflare Tunnel).

## Что умеет

**Чаты**: личные, группы, каналы (только админы пишут, подписка по `@handle` или ссылке `/?start=handle`),
Избранное, секретные чаты со сквозным шифрованием (ECDH P‑256 + AES‑256‑GCM прямо в браузере).

**Сообщения**: ответы, редактирование, удаление, пересылка, реакции, избранное (звёздочка), поиск по чату
и глобальный, форматирование (`**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `код` ``, `||спойлер||`,
`@упоминания`, ссылки), фото с превью и лайтбоксом, любые файлы до 10 МБ (drag‑and‑drop / вставка из буфера),
голосовые сообщения с аудиоплеером, индикатор «печатает», галочки доставки/прочтения, черновики.

**Звонки**: аудио/видео 1:1 напрямую через WebRTC (P2P, шифрование DTLS‑SRTP), **демонстрация экрана**,
переключение камеры/микрофона, свёрнутый режим, полноэкранный режим, индикатор качества, лог звонков в чате.
Групповые звонки — через LiveKit (SFU) при наличии ключей в `.env`.

**Организация**: папки чатов (по типам и конкретным чатам), закрепление, «без звука», скрытие чата,
очистка истории, непрочитанные, счётчик во вкладке браузера, системные уведомления и звуки.

**Профиль и настройки**: аватар, имя, «о себе», три темы (тёмная / полночь / светлая), размер шрифта,
Enter/Ctrl+Enter, приватность (последний визит, отчёты о прочтении, кто может звонить/писать),
блокировка и жалобы, смена пароля, активные сессии с возможностью завершить.

**Боты**: создание ботов с API‑ключом, добавление в чаты, HTTP API:
`POST /api/bot/<token>/sendMessage {"chat_id":"...","text":"..."}`, `GET /api/bot/<token>/me`.

Горячие клавиши: `Ctrl+K` — поиск, `Ctrl+F` — поиск по чату, `↑` — редактировать последнее, `Esc` — закрыть.

## Структура

- `server.js` — Express + Socket.IO, данные в `data/store.json`, файлы в `data/files/`
- `index.html` — весь фронтенд (HTML + CSS + JS без сборки и фреймворков)
